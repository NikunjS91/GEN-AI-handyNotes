today we will build a qna chat bot using langgraph
based on the user question a complete graph will be followed, from user question to generating answer,
question and response of it, in the form of memeory we are going to store it, for generating a relative answers.

---

first load the env variables

```python
from dotenv import load_dotenv
load_dotenv()
```

then import everything we need

```python
from langchain_groq import ChatGroq
from pydantic import BaseModel
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.checkpoint.memory import InMemorySaver
from typing import Annotated
```

define the chat state, messages is a list and add_messages means it will keep appending new messages instead of replacing, this is how memory builds up

```python
class ChatState(BaseModel):
    messages: Annotated[list, add_messages]
```

initialize the llm

```python
llm = ChatGroq(model="openai/gpt-oss-20b")
```

the chatbot node takes the current state which has the full message history, sends it to the llm and returns the response

```python
def chatBotNode(state: ChatState) -> ChatState:
    res = llm.invoke(state.messages)
    state.messages = [res]
    return state
```

InMemorySaver is the checkpointer, it saves the graph state between invoke calls so the bot remembers previous messages

```python
memory = InMemorySaver()
```

build the graph, add the node, connect start to chatbot to end, compile with the memory checkpointer

```python
graph = StateGraph(ChatState)
graph.add_node("ChatBot", chatBotNode)

graph.add_edge(START, "ChatBot")
graph.add_edge("ChatBot", END)

graph = graph.compile(checkpointer=memory)
```

visualize the graph

```python
from IPython.display import Image
Image(graph.get_graph().draw_mermaid_png())
```

run the chatbot, thread_id ties the memory to a specific conversation session, same thread_id = bot remembers previous messages

```python
config = {"configurable": {"thread_id": "my-bot-1"}}
res = graph.invoke({"messages": [{"role": "user", "content": "what is my name?"}]}, config)
print(res["messages"][-1].content)
# Output: Your name is Nikunj.
```

res["messages"][-1].content gives us the last llm response

---

examples

multi turn conversation, using the same thread_id so the bot remembers everything from previous turns

```python
config = {"configurable": {"thread_id": "my-bot-1"}}

res = graph.invoke({"messages": [{"role": "user", "content": "my name is nikunj"}]}, config)
print(res["messages"][-1].content)
# nice to meet you nikunj! how can i help you?

res = graph.invoke({"messages": [{"role": "user", "content": "what is my name?"}]}, config)
print(res["messages"][-1].content)
# your name is nikunj.

res = graph.invoke({"messages": [{"role": "user", "content": "summarize what we talked about"}]}, config)
print(res["messages"][-1].content)
# you told me your name is nikunj and then asked me to recall it.
```

after 3 turns res["messages"] has 6 messages total, 3 human and 3 ai, all accumulated in order

what the messages list looks like inside

```python
for msg in res["messages"]:
    print(type(msg).__name__, ":", msg.content)

# HumanMessage : my name is nikunj
# AIMessage    : nice to meet you nikunj!
# HumanMessage : what is my name?
# AIMessage    : your name is nikunj.
# HumanMessage : summarize what we talked about
# AIMessage    : you told me your name is nikunj...
```

this is why llm.invoke(state.messages) always sends the full history, not just the latest message

different thread_id = completely separate memory, useful when supporting multiple users

```python
config_1 = {"configurable": {"thread_id": "session-a"}}
config_2 = {"configurable": {"thread_id": "session-b"}}

graph.invoke({"messages": [{"role": "user", "content": "my name is nikunj"}]}, config_1)

res = graph.invoke({"messages": [{"role": "user", "content": "what is my name?"}]}, config_2)
print(res["messages"][-1].content)
# i don't know your name, you haven't told me!
```

to inspect what the checkpointer has stored between turns

```python
state = graph.get_state(config)
for msg in state.values["messages"]:
    print(f"{type(msg).__name__}: {msg.content}")
```
